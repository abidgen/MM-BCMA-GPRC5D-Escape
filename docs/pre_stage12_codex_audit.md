Audit date: 2026-08-26  
Scope: read-only scientific/software audit of the repository at `4a2b809` (`main`) and the locally present ignored artifacts under `results/`. Stage 12 was not started and no analysis result, threshold, state, or tier was changed.

## Executive summary

The repository is scientifically more disciplined than most exploratory single-cell projects: patient-level aggregation is explicit, antigen circularity is guarded in Stages 07 and 10, depth is treated as the dominant technical limitation, CNV failure is reported as `NOT_EVALUABLE`, bulk is restricted to marginal validation, the Stage-10 hierarchy is now correctly separated, and Stage 11/LIANA remain exploratory negative results. The locally present tables are mutually consistent with the main documented counts and the complete test suite passes (517 passed, 2 skipped).

The repository is nevertheless **not safe for Stage 12** in its current archival state. The decisive defect is reproducibility/provenance, not a demonstrated wrong number: commit `4a2b809` removed generated results from Git and `.gitignore` excludes all of `results/`, while authoritative notebooks for substantial parts of Stages 07–10 only read precomputed outputs and do not contain the code that produced them. A clean checkout therefore cannot recreate or authenticate several frozen claims that Stage 12 is supposed to synthesize. Local digest files establish present-day equality with a recorded local state, but because the digest manifests and targets are themselves ignored and unversioned they do not provide an independent historical checkpoint.

Finding count: **1 CRITICAL, 2 HIGH, 8 MEDIUM, 6 LOW**. I found **no direct evidence that a currently frozen numerical result is invalid**. I did find insufficient committed implementation evidence to certify several such results as reproducible.

## Is Stage 12 safe to begin?

**NO.** Before Stage 12, the repository needs a reviewable, committed, executable production path (or an immutable manifest plus archived artifacts) for the currently orphaned Stage 07–10 results, and an independently anchored frozen-artifact manifest. This can be done without changing any scientific result.

- **File/section:** `notebooks/07_malignant_plasma.py`; `notebooks/08_dual_antigen_escape.py`; `notebooks/09_bulk_validation.py`; `notebooks/09b_risk_tiers.py`; `notebooks/10_dn_coherence.py`; `.gitignore:36`; commit `4a2b809`.
- **Evidence:** Stage 09, 09b, and 10 notebooks contain no output-writing calls and read the final CSVs they discuss. Stage 10 reads `stage10_evaluability.csv`, `dn_coherence_final_states.csv`, `level2_program_cohort_tests.csv`, `pseudobulk_de_results.csv`, and other products, but no committed source implements the per-patient embedding, pydeseq2 fit, decoupler run, or construction of those tables. Stage 08 writes only the primary/sensitivity patient tables; the technical-zero, ambient, repeated-sample, truncation, evidence-state, and risk-tier design products are not all generated by the committed notebook. Stage 07 computes light-chain/V membership, but the committed production path for CNV calibration and several design artifacts is absent. `git log --all -- results/07_malignant_plasma ... results/11_immune_context` contains no archived Stage 07–11 artifacts, and `git ls-files results` returns zero.
- **Why it matters:** Stage 12 would consume conclusions whose derivation cannot be independently rerun or code-reviewed from a clean checkout. Passing tests against local CSVs cannot replace the missing production implementation.
- **Severity/type:** **CRITICAL — reproducibility issue / provenance issue.**
- **Recommended action:** before Stage 12, recover and commit the exact production drivers (without recomputing or changing results), or archive immutable result objects plus a complete checksummed input/code/environment manifest and document which outputs are intentionally non-recomputable. Then review the recovered code against the frozen numbers.

### H1 — Frozen-artifact integrity checks are locally consistent but not independently anchored

- **File/section:** `notebooks/08c_multi_antigen_coverage.py:64-92`; `tests/test_coverage.py:test_i_supplemental_analysis_wrote_nothing_into_a_frozen_namespace`; `notebooks/11b_liana_verification.py:667-679`; `tests/test_liana_verification.py:test_hi_liana_did_not_modify_any_frozen_tier_state_or_custom_lr_output`.

- **Recommended action:** commit a top-level checksum manifest (including code commit, environment lock/version export, sizes, and all Stage 06–11/08c files) or store the frozen bundle in immutable external storage. Record hashes before and after each supplemental run.

### H2 — Stage-10 Level-2 patient classification is almost non-discriminative

- **File/section:** `src/mm_escape/subclone.py:level2_state`; `notebooks/10_dn_coherence.py`, “LIMITATION — the per-patient Level-2 rule turned out near-vacuous”; `results/10_dn_coherence/stage10_evidence_levels.csv`.

- **Severity/type:** **HIGH — scientific-method issue / code bug.**
- **Recommended action:** do not retune the frozen rule. In Stage 12, emphasize the cohort-level program result and explicitly label the 26/27 state as weakly discriminative. Before Stage 12, add reviewable input validation/tests without changing frozen calls, or constrain construction upstream in the recovered production driver.

### Antigen circularity and mature-plasma selection dependence

Stage 07 clone calling excludes both antigens by interface. Stage 10 drops both count columns before normalization, protecting PCA, neighbors, clustering, DE inputs, and programs; predeclared programs contain neither gene. Failed CNV is not reused. `SDC1` and `TNFRSF17` do participate in the Stage-06 mature-plasma predicate. Therefore SDC1-negative cells are selection-depleted and SDC1 comparative coverage is invalid; excluding SDC1 is correct. TNFRSF17 has the same structural qualification, but the accepted Stage-08 denominator was defined before this issue was recognized and the effect is bounded: the predicate is an OR plus independent plasma identity/clone evidence, not a direct TNFRSF17-positive filter. This weakens “absolute BCMA-negative prevalence” interpretation; it does not demonstrate that the computed Stage-08 fractions are arithmetically wrong or require reopening them.

### Depth handling

The audit found four intentionally different quantities: QC `total_counts` over each original reference; intersected-space row sums; antigen-excluded depth; and `n_genes_by_counts`. Stage 08/10/11/08c use antigen-excluded depth where circularity matters. Stage 08 defines cohort-specific primary edges, merges sparse patient strata, supplies a global-bin diagnostic, and recomputes after truncate-10k. Stage 10 uses patient-adaptive 2–10 bins following the synthetic failure of fixed quintiles. Stage 08c reads frozen Stage-08 strata and delegates genuine re-stratification to `antigen.py`. Ties are handled by unique quantile edges; sparse strata merge deterministically. Seeds are fixed for permutations/bootstrap/downsampling. Remaining risk is duplicated wrapper/bin logic and ambiguous total-count naming, not a demonstrated current numerical defect.
